# QR Code Wizard

A clean, zero-backend static QR code generator.

- **Live:** https://jarbochov.github.io/qr-wizard/
- **Features:** URL, plain text, WiFi, email, phone, SMS, vCard, calendar event, and geo QR codes with custom foreground/background colors, transparency, dot/corner styles, logo overlays, contrast check, `localStorage` presets, shareable hash links, and PNG/SVG/clipboard export.

> **Note:** QR codes encode static text only. If you may need to change a link's destination after printing or sharing, encode a **URL forwarder** — ideally a **redirect on a domain you control**.
